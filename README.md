# CodeAlpha Data Analytics Internship - Task 1

## Web Scraping and Exploratory Data Analysis

This project was completed as part of my Data Analytics Internship at CodeAlpha.

## Objective

The objective of this project is to collect publicly available book information using web scraping and perform data cleaning, exploratory data analysis, and visualization.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Collected

The dataset contains:

- Book Title
- Price
- Rating
- Availability
- Image URL
- Source Page

## Project Workflow

1. Website selection
2. HTML inspection
3. Web scraping
4. Dataset creation
5. Data cleaning
6. Exploratory Data Analysis
7. Data visualization
8. Statistical analysis
9. Dataset export

## Visualizations

The project includes:

- Rating distribution
- Price distribution
- Price range analysis
- Price vs rating analysis
- Average price by rating
